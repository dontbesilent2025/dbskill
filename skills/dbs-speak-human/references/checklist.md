# 说人话检查清单

来源：作者改稿时指出的常见问题，案例已换成通用场景。每条附原句与改句，按问题类型排列。新增条目时保留原句与改句，案例同样换成通用场景，不写真实业务、价格、人名和日期。

## 一、对方的分寸

| 问题 | 原句 | 改句 | 为什么 |
| --- | --- | --- | --- |
| 预设对方要谈 | 先聊聊你的情况 | （删去） | 对方只是来问一句，被拉进「聊聊」会有压力 |
| 预设对方有问题 | 方便你随时问 | 有问题的话这边能及时回你 | 写我们这边的安排，并加「有问题」的条件 |
| 姿态过满 | 我来帮你看 | 我可以来看看 | 不揽活，语气轻 |
| 替对方限定范围 | 你自己家里的具体情况 | 具体情况 | 「你自己」多余，也有点指着对方说 |
| 替对方挑刺 | 选这套你还能多拿到什么 | 这套还多了些什么 | 从自己这边说，不替对方质问 |
| 多余的保证 | 不合适的我们也会直接告诉你 | （删去） | 对方没问，主动说反而奇怪 |

## 二、提问与结尾

| 问题 | 原句 | 改句 | 为什么 |
| --- | --- | --- | --- |
| 书面腔提问 | 你现在最想弄清楚的是哪个？ | 有类似的或者别的问题，直接问我就行～ | 问句 AI 味重；改成随口的邀请，对方不用马上回答 |
| 开放邀请太正式 | 如果有类似的或者其他疑问，可以直接问我 | 有类似的或者别的问题，直接问我就行～ | 去掉「如果」「可以」；「疑问」「其他」换成口语 |

## 三、标点与句式

| 问题 | 原句 | 改句 | 为什么 |
| --- | --- | --- | --- |
| 分号 | 同事都能第一时间回你；方案上的事，还有具体的细节，我可以来看看 | 同事都清楚。方案上的事，还有具体的细节，我可以来看看 | 聊天里不用分号，拆成两句 |
| 冒号加「比如」重复 | 之前经常有人问我这几个问题：比如…… | 之前经常有人问我，比如…… | 留一个就够 |
| 分号列清单 | 自己的情况能不能做；预算不多，这个方案合不合适；…… | 自己的情况能不能做，预算不多合不合适，…… | 逗号连成一口气，不像念清单 |
| 拗口 | 方便有问题可以及时回复你 | 有问题的话这边能及时回你 | 「这边」「回」更口语 |

## 四、用词

| 书面或客服词 | 口语 |
| --- | --- |
| 同事都能第一时间回你 | 同事都清楚（不替别人打包票） |
| 提供哪些内容 | 多了些什么／给什么 |
| 疑问 | 问题 |
| 其他 | 别的 |
| 回复 | 回 |
| 一般（概括别人） | 之前经常有人……（只在属实时用） |
| 内部叫法，如「X 档价」 | 直接说具体情况和数字，如「两件一起买，每件便宜 X 元」（对方不知道内部叫法指什么） |

## 五、Agent 自己的回复

| 问题 | 例子 | 改法 |
| --- | --- | --- |
| 公文标题包装短内容 | 「## 当前判断」「## 本轮方案」套在三句话外面 | 直接说结论 |
| 堆术语 | 「信息增量」「认知负荷」 | 用对方的说法，必要时一句话解释 |
| 先铺垫后结论 | 「我对照了两版的差别，看出……」 | 先说结论，再说理由 |

## 六、评价词代替内容

一个字只给出评价（好、完整、对上了、有力），把本该写出的具体内容省掉了。改法：写出它具体指什么；原文没有就删掉或问用户，不编造，不换同义评价词。

| 分组 | 字 | 常见搭配 | 省掉了什么 |
| --- | --- | --- | --- |
| 完整、彻底 | 透 | 讲透、想透、吃透、打透、点透 | 讲到了哪一层，哪几件事 |
| | 通 | 打通、跑通、讲通、拉通 | 哪些步骤接上了，原来断在哪 |
| | 满 | 拉满、做满、情绪拉满 | 做到了什么程度，用什么衡量 |
| | 实 | 做实、夯实、落实、压实 | 具体做了什么动作 |
| | 全 | 讲全、补全、全链路 | 缺了哪些，补了哪些 |
| | 尽 | 讲尽、榨尽 | 同上 |
| 流畅 | 顺 | 理顺、顺一下、读着顺 | 原来哪里卡，现在怎么接上 |
| | 滑 | 丝滑、顺滑 | 少了哪一步操作或停顿 |
| 对上了 | 贴 | 贴合、贴着、贴近、很贴 | 和谁的什么对上了 |
| | 准 | 精准、打得准、说得准 | 准在哪，依据是什么 |
| | 对 | 对齐、对上 | 哪两样东西，哪一项一致 |
| | 契 | 契合 | 同「贴」 |
| 力度 | 狠 | 够狠、下狠手、狠抓 | 具体动作和程度 |
| | 硬 | 硬核、很硬、硬实力 | 硬在哪，什么证据 |
| | 重 | 重拳、重磅 | 实际做了什么 |
| | 猛 | 很猛、猛药 | 同上 |
| 抓住人 | 戳 | 戳中、戳到痛点 | 说中了对方的哪句话、哪件事 |
| | 抓 | 抓手、抓住、抓眼球 | 具体用什么做到的 |
| | 击 | 击中、击穿 | 同「戳」 |
| | 接 | 接住、承接 | 对方给了什么，你回了什么 |
| | 勾 | 勾住、勾人 | 哪一句让人想往下看 |
| 稳、收住 | 稳 | 稳住、很稳、稳稳的 | 哪项不波动，波动多少 |
| | 住 | 立住、压住、兜住、收住 | 立住了什么判断，靠什么 |
| | 牢 | 牢牢、筑牢 | 同「稳」 |
| | 收 | 收口、收敛、收一下 | 最后落到哪个结论 |
| | 兜 | 兜底 | 出问题时谁做什么 |
| 落地、沉下来 | 落 | 落地、落到 | 具体在哪个场景做了哪一步 |
| | 沉 | 沉淀、下沉 | 留下了什么文件、规则或数据 |
| | 扎 | 扎实、扎根 | 做了多少，做了多久 |
| 打开局面 | 破 | 破圈、破局、点破 | 原来卡在哪，现在多了谁 |
| | 活 | 盘活、激活、用活 | 原来闲着的什么，现在用来做什么 |
| | 撬 | 撬动 | 用什么换来了什么 |
| | 闭 | 闭环 | 从哪开始，到哪结束，结果回到了哪 |
| 打磨 | 磨 | 打磨、磨一下 | 改了哪几处 |
| | 抠 | 抠细节 | 哪个细节，改成了什么 |
| | 炼 | 提炼、凝练 | 提出来的那句话是什么 |
| 夸张评价 | 绝 | 绝了 | 好在哪 |
| | 炸 | 炸裂、炸场 | 实际反应或数据 |
| | 爆 | 爆款、爆点 | 播放量或其他数字 |
| | 神 | 神来之笔 | 好在哪 |

不算问题的情况：字面意思或固定名词，例如透明、顺序、贴图、准备、接电话、闭门会、爆炸。判断标准：这个字是不是在评价一件抽象的事，同时把本该写出的内容省掉了。

| 原句 | 改句 | 为什么 |
| --- | --- | --- |
| 把这个概念讲透 | 讲清它从哪来、和「选题」有什么区别 | 写出讲到的具体内容 |
| 帮你把这段理顺 | 把第 3 句挪到第 1 句前面 | 写出具体动作 |
| 让回复贴着你的需求 | 回复里写的是你刚才提的两个问题 | 写出和什么对上了 |
| 这篇会把装修预算讲透 | 这篇会讲预算怎么拆、哪几项最容易超 | 原文有信息，就用原文的内容替换 |

来源：作者改稿时发现 Agent 回复里常用「贴」「透」「顺」这类字。
