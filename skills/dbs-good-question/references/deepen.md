# 深度升级探针（deepen.md）

`dbs-good-question` 模式 E 与 Phase 2.5 的展开，按需读取。

用途：题目已经说清但**不够深**时，用四个探针把它升级到专家级。

**核心区分：更深的题 ≠ 更大的题。**

- **更大** = 范围扩张、交付物变多、耗时变长，推理链没变。
- **更深** = 同一件交付物，证据层数增加、可证伪性提高、必须经过中间推导。

升级只做后者。判据见 §3，输出模板见 `references/output-formats.md` 的「深度升级」。

---

## 探针 1：专家差距（Expert Gap）

**问**：把题交给这个领域公认的 SOTA 从业者，他会额外做哪 3 件我没有要求的事？

**约束**：

- 必须是**动作**，不是形容词。「做更深入的调研」「多想想」不合格；「去调原始财报而不是二手摘要」合格。
- 说不出具体是谁（真实的人、流派、公认标准）时，退化为「这个领域公认 SOTA 从业者的标准动作」，但仍要给动作。
- 每条差距必须能指出**交付物的哪一部分会被替换或新增**。指不出来的，删掉。

**常见伪装**：

- ❌「他们会考虑更多维度」——形容词，不可判定
- ✅「他们会先看流失用户的原始访谈，而不是看用户填的问卷」——动作，且改交付物

## 探针 2：回到一手素材（Re-grounding）

**问**：这个领域的顶尖从业者会从哪些**原始素材**入手，而不是我已经整理好的那些？

**定义**：

- 一手 = 原始文档 / 原始数据 / 原始访谈录音 / 源码与提交记录 / 原始交易或合同 / 一手观测
- 二手 = 别人整理好的框架 / 总结 / 报告 / 转述 / 我自己的归纳

**关键动作**：把我给的二手材料**降级为「线索」**，把一手材料**升为「必需输入」**。这一步会改变题目本身，不是加一句建议。

**必须同时回答**：拿不到这个一手来源怎么办。写明降级方案，或写明这个问题在缺少该来源时不可解。**不要假装能拿到。**

## 探针 3：方法与工具（Method & Tool）

**问**：这个领域的顶尖从业者会用什么**具体方法**和**具体工具**？

**约束**：

- 方法要有名字：对比分析、事件研究、留存曲线、反向推导、影子定价、净推荐值、幸存者偏差校正……不给空泛动词。
- 工具要落到动作：查原始财报、跑 A/B、看 commit history、扒历史价格、约访真实用户。
- ❌「用数据驱动」「借助 AI 的力量」「多维度分析」——装饰性专业感，不合格。
- 每条方法必须**能改变结论**。改不了结论的方法是姿态，不是深度。

## 探针 4：独立验证锚点（Independent Verification）

**问**：除了提问者和 AI，还有谁能独立证明结果是对的？

**约束**：

- 答案必须落在**第三方可观测的证据**上：可查的公开数据、可复核的原始记录、能重跑的实验、领域内公认的判定标准。
- ❌「让用户自己判断」「再检查一遍」「多问几次」——同一个信息源，不是独立验证。
- ✅「交易所公开披露的季度财报能核对这笔交易的量级」「同一个实验换个数据集结论若翻转则不成立」

**必须写全三件**：验证方是谁、验证的具体可观测量、什么结果算通过。

## 3. 深度判据（防「更大」）

升级后的题目必须同时满足：

| 判据 | 检验方式 |
|---|---|
| **证据层数** | 升级前依赖几层二手？升级后要求几层一手？（目标 ≥2 层一手） |
| **可证伪性** | 有没有一个具体观察，结果若是错的能被看出来？ |
| **推理深度** | 结论是否必须经过中间推导（A→B→C）得出，而非直接检索可得？ |
| **单件密度** | 交付物数量**不变**。要加第二份报告 = 更大，不是更深。 |

**深度预算**（防无限加码）：

- 专家差距动作 ≤ 3
- 一手素材要求 ≤ 1 类
- 方法 ≤ 3
- 验证锚点 = 1

超出预算，深度就不受控了。

**停止规则**：如果差距清单里的动作**不改变任何结论的可能性**，它不是深度，是姿态——删掉。宁可交付更少但更硬的动作。

## 4. 与五项检查的接口

深度升级在 Phase 2（五项检查）之后、Phase 3（可解性判断）之前执行。

- Phase 2 解决「松不松」
- 深度升级解决「够不够深」
- Phase 3 解决「能不能自动做」

深度升级往五项检查回填三处：

- **背景事实** → 降级为线索，补一手素材要求
- **约束** → 补「交付物数量不变」和「缺一手来源时怎么办」
- **反馈入口** → 用独立验证锚点替换或强化原来的反馈项

## 5. 分工边界

本模式只做**改题**：把一道已经说清但太浅的题，升级成专家级的题。它不负责给出答案。

刻意不做的两件事：

- **理论溯源与历史同构比较**——找出这个领域可信的理论，把同机制的历史成功与失败案例并排比较。这是答案层的能力，比题目本身更深也更贵。探针 1 和探针 3 需要更硬的领域理论时，用一句话说明还需要这类能力，不要自己临场编一套理论充数。
- **传播机制解读、逐句改稿、发布风险检查**——那是内容层的事，升级后的题目会自然指向其中需要的一环。

探针 3 在没有外部理论支撑时，照样要给方法和工具清单，但必须标注这是基于通用认知的判断，领域专属方法需要进一步确认。

任何情况下，模式 E 的终局产物都是**题目**，不是答案。

---

## 6. 反例

| 反例 | 问题 |
|---|---|
| 「请深入研究这个市场，出一份 50 页报告」 | 更大不是更深：交付物变多，推理链没变 |
| 「请从第一性原理分析这个商业模式」 | 姿态：没有具体方法、没有可证伪性 |
| 「请交叉验证所有结论，确保万无一失」 | 伪独立验证：验证方还是提问者自己 |
| 「请参考更多数据源，从更多角度思考」 | 空泛：说不出具体哪一手、哪方法、哪可观测量 |
| 「专家会做更深的分析」 | 形容词：不可判定，不可执行 |
